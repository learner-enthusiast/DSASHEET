## 📋 Revision Strategy

### Every Sunday Schedule (6-7 hours):

- **9:00 - 10:30 AM**: Arrays (8)
- **10:30 - 11:15 AM**: Strings (5)
- **11:15 - 12:15 PM**: Linked List (6)
- **12:15 - 12:45 PM**: Stack/Queue (4)
- **1:45 - 3:15 PM**: Binary Tree (8)
- **3:15 - 4:00 PM**: Binary Search (4)
- **4:00 - 5:00 PM**: Graphs (5)
- **5:00 - 6:30 PM**: Dynamic Programming (6)
- **6:30 - 7:00 PM**: Backtracking (2)
- **7:00 - 7:20 PM**: Greedy (2)

### Tips:

1. ⏱️ **Time yourself** - 15-20 mins per problem max
2. 🎯 **Focus on approach first** - Don't code immediately
3. 📝 **Write key points** - Note down the pattern/technique
4. 🔁 **Code from scratch** - No looking at old solutions
5. 🗣️ **Explain out loud** - Practice talking through your approach

### If Short on Time (3-hour version):
